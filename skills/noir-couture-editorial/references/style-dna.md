# Noir Couture Editorial — Visual Style DNA

Use these palette, layout and lighting defaults to keep a series consistent. Adapt the grid to the dimensions and copy supplied in the brief.

## 2. Dual-Mode Layout Grids (3:4 Portrait)

### Mode A: `poster` (Full-Body Avant-Garde Couture Poster)

```text
+-----------------------------------------------+
| [Top-Left Display Title]    [Upper-Right Tag] |
|  e.g. 锐度 / 秩序             新中式 / 时装企划 |
|  ~~~crimson brush~~~         (or vertical     |
|                               poetic lines +  |
| [Left-Mid Subheads]           thin red rule)  |
|  锋芒 · 重塑 · 优雅                            |
|  HIGH FASHION EDITORIAL                       |
|  -- (short crimson bar)                       |
|                                               |
|            [ CENTERED FULL-BODY ]             |
|            [  RUNWAY COUTURE    ]             |
|            [  MODEL SILHOUETTE  ]             |
|                                               |
| [Lower-Left Metadata]                         |
|  VOL. 01 (red 01)                             |
|  结构廓形 / 定制剪裁                            |
|  流线设计 / 现代美学         (optional crimson |
|                              dry-brush sweep) |
+-----------------------------------------------+
```

- **Safe Margins**: Keep left and right 22%–26% columns clean around the waist/skirt edges or reserve open studio backdrop space so text never collides with the model's face or torso details.
- **Floor Grounding**: Always render full shoes (pointed stilettos or tailored leather boots) grounded on a faint matte concrete studio floor with natural soft contact shadows.

### Mode B: `cover` (Luxury Editorial Magazine Cover)

```text
+-----------------------------------------------+
| [  GIANT EDGE-TO-EDGE DIDONE MASTHEAD  ]      |
| [   e.g. A T E L I E R  /  C O U T U R E ]    |
|     (Model crown & hair overlap IN FRONT)     |
|                                      [MEN]    |
| [Left Cover Block]             [AUTUMN 2026]  |
|  FASHION STYLE                                |
|  -- (2px crimson dash)                        |
|  冬季高定 / 时装特辑                            |
|  Winter Couture                               |
|                                               |
|            [ MEDIUM-CLOSE / 3-QTR ]           |
|            [   SEATED EDITORIAL   ]           |
|            [       PORTRAIT       ]           |
|                                               |
|                       [Bottom-Right Hero Copy]|
|                        黑曜绅士                |
|                        Noir Gentleman         |
|                        -- (2px crimson dash)  |
|                        高定 × 大衣 × 质感      |
+-----------------------------------------------+
```

- **Depth Rule**: The masthead spans nearly 90%–96% of top canvas width in condensed high-contrast Didone serif (`#F4F2EE`), sitting cleanly **behind** the model's head/hair/hairpin.
- **Sub-Tag Alignment**: Tuck `MEN`, `FASHION`, or `VOL. 126` immediately beneath the right or left descender line of the masthead.

## 3. Garment-Driven Typography & Graphic Accent Rules

Typography is **never one-size-fits-all**. Avoid defaulting to generic heavy Songti or repetitive `"高定时装"` clichés—match the font personality (inspired by free/open-source font families or bespoke AI-designed custom lettering) directly to the garment's material, cut, and silhouette:

### Garment-to-Typography Design Matrix

| Garment Archetype | Recommended Chinese Display Style | Recommended English Font Style | Example Thematic Titles |
| :--- | :--- | :--- | :--- |
| **Dark Lace / Sheer Organza / Suspender Couture** | Bespoke AI slender silk-ribbon calligraphy / slender-gold (`瘦金体 × 细行书`) with razor-sharp tapering terminals or airy *LXGW WenKai* light strokes | Fine romantic italic serif (*Cormorant Garamond Italic* / *Playfair Display Italic*) | `夜纱织影`, `暗夜序曲`, `丝影浮光` |
| **Neo-Chinese (`新中式`) / Ink Jacquard** | Expressive dry-brush running calligraphy (`行草飞白`, *Jiangxi Zhuokai* / *Ma Shan Zheng* spirit) | Classic engraved serif (*Cinzel* / *Bodoni Moda*) | `墨韵新衣`, `松烟入画`, `青黛未央` |
| **Architectural Tailoring / Deconstructed Trench** | Razor-sharp ultra-condensed sans or bespoke AI split-stroke deconstructivist lettering (*Noto Sans SC* / geometric cut) | Wide geometric display or sharp modernist sans (*Syne* / *Space Grotesk*) | `解构重塑`, `锐度秩序`, `锋线纪元` |
| **Liquid Metallic / Pleated Avant-Garde** | Bespoke AI-designed liquid chrome / blade-edge sculptural metallic lettering echoing garment specular sheen | Avant-garde wide extended display (*Syne* / sharp italic serif) | `银翼秩序`, `液态极光`, `折光之形` |
| **Deep Crimson Satin / Dramatic Evening Gown** | Theatrical ribbon-stroke calligraphy / expressive swash display echoing billowing satin drapes | High-contrast romantic italic serif (*Cormorant Garamond* / *Bodoni Moda Italic*) | `红韵织梦`, `绯色序章`, `赤帛惊鸿` |
| **Menswear Tailoring / Minimalist Overcoat** | Ultra-thin refined editorial serif or minimalist light condensed sans (*Noto Serif SC Light* / fine Songti) | High-contrast luxury magazine serif (*Bodoni Moda* / *Libre Baskerville*) | `黑曜绅士`, `凛冬风骨`, `静默剪裁` |

- **Body & Metadata Pairing**: Keep supporting bullet lines crisp and lightweight (zero drop shadows, zero 3D bevels, zero WordArt glows) so the bespoke hero title remains the clear typographic focal point.

### The Five Canonical Crimson Motifs (Pick 1–2 per Image)
1. **Dry-Brush Slash Underline**: Angled coarse vermilion brushstroke directly beneath the Chinese main title.
2. **Micro 2px Horizontal Bar**: Short ~18–28px solid crimson divider between Chinese and English copy blocks.
3. **Vertical Margin Seal Rule**: Thin 1px vertical crimson line framing right-aligned vertical Chinese poetry (`当力量遇见优雅`).
4. **Vermilion Pill Seal (`印章`)**: Small vertical crimson oval/rectangle stamp with crisp white Chinese text (`系列`, `新季`).
5. **Atmospheric Backdrop Ink Sweep**: One sweeping, low-opacity dry-brush crimson arc crossing the dark background behind the lower skirt/hem.

## 4. Photography & Lighting Recipe

- **Camera & Lens**: Medium-format fashion studio photography aesthetic (Phase One / Hasselblad look), 85mm–100mm focal length, f/4–f/5.6 for full sharpness across eyes and couture embroidery, crisp micro-contrast, fine organic grain.
- **Lighting Setup**:
  - **Key Light**: Large octabox positioned high 35° camera-left/right creating sculpted cheekbones, collarbone highlights, and deep velvety shadow transitions on folds.
  - **Rim/Hair Light**: Subtle cool-neutral kicker separating dark hair, shoulders, and organza edges from the dark backdrop.
  - **Skin & Retouching**: Luminous editorial skin with preserved natural pores and realistic highlights (never plastic airbrushing or waxy CGI skin).

## 5. Styling Taxonomy (Tasteful Couture Only)

- **Architectural Womenswear**: Structured padded-shoulder ivory tuxedo blazer-gowns, dramatic asymmetric floor-length draped trains, crisp pleated suiting, pointed heels.
- **Dark Romantic Lace & Couture Hosiery**: Sculpted obsidian floral-embroidered silk & sheer organza halter or corseted dresses with opaque tailored mini/midi skirts and sweeping organza back trains, paired with sheer misty-pearl or charcoal silk stockings (including tasteful lace-top thigh-high stockings and sleek black satin suspender clips beneath structured hems — zero nudity or boudoir framing).
- **Neo-Chinese (`新中式`) Couture**: High-collar embroidered silk jacquard bodices, delicate frog closures (`盘扣`), flowing translucent charcoal organza sleeves, tiered ink skirts, sleek chignon updo with silver hairpins (`发簪`) and fine linear tassel earrings.
- **Metallic Avant-Garde**: Accordion-pleated liquid silver asymmetrical evening gowns catching directional studio specular highlights.
- **Menswear Gentleman**: Tailored double-breasted charcoal or obsidian wool trench/overcoats layered over fine-ribbed black turtlenecks, minimalist geometric silver pendant necklace, brushed steel dress watch, tousled textured dark waves.

---

## 6. Anti-Drift Negative Constraints

Always steer prompts **away** from:
- Stiff default computer Songti headers mismatched to fluid/avant-garde outfits, or repetitive boilerplate titles (`高定时装`, `高级时装`).
- Neon lights, cyberpunk glows, busy outdoor streets, cluttered room props, colorful gradients.
- Cartoon, 3D CGI plastic skin, anime proportions, overly smooth airbrushed faces.
- Trademarked logos (`VOGUE`, `ELLE`, `BAZAAR`) or fake barcodes/prices crowding the cover.
- Explicit nudity, boudoir/lingerie-only posing, or anatomically distorted hands/heels.
- Dense blocks of small Chinese text or glowing/3D-extruded lettering. Use the copy budget in the main skill when selecting optional lines.
